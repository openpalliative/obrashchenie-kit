# Данные obrashchenie-kit

Всё, что видят люди на сайте, собирается из этой папки. Правки только через PR, тексты документов и сроки смотрит юрист в РФ.

| Файл | Что внутри |
|---|---|
| `meta.yaml` | версия пакета и дата последней сверки |
| `sources.yaml` | источники с адресом и датой |
| `scenarios.yaml` | 5 страниц-входов: что сделать сейчас, какие документы, что если не получилось |
| `entrypoints.yaml` | что kit показывает на главной openpalliative |
| `pack/pack.yaml` | статус пакета (демо), ревьюеры, срок годности, дата первой публикации |
| `pack/fields.yaml` | общие поля (заявитель, представитель, адресат, подпись) и общие блоки текста |
| `pack/documents/*.yaml` | 6 документов T0: поля, блоки текста, запасные формулировки |
| `pack/graph.yaml` | лестница шагов: при каком условии какой документ и куда |
| `pack/reply-types.yaml` | что могло прийти в ответ |
| `pack/channels.yaml` | как подать: бумага, электронное заказное письмо, формы через Госуслуги |
| `pack/addressees-federal.yaml` | федеральные адресаты, только ссылки |
| `pack/turning18.yaml` | вехи «Ребёнку скоро 18» |
| `schema/*.schema.json` | схемы публикуемых наборов и файла дел |
| `snapshots/upstream.json` | версии снимков соседей на дату последней сверки |

## Правила текста документа

- номер акта в тексте не пишется никогда. Ссылка только так: `{{norm:180n#p-16}}`, и у блока обязательно есть `fallback` без нормы
- срок в тексте документа не пишется, только «в установленный срок». Дата ответа считается на экране дела
- поля человека: `{{applicant_name}}`, дата словами: `{{date:filed_at}}`
- без латиницы, названия проекта, препаратов и доз

Если норма в снимке pal-norms не проверена или не действует, в документ идёт `fallback`. Если норма отменена, сборка падает.

## Команды

```sh
uv run python -m pipeline.pack_lint            # проверить пакет
uv run python -m pipeline.seed_vendor          # тестовые снимки соседей, если настоящих ещё нет
uv run python -m opsite sync-data --from local # настоящие снимки из соседних репо
uv run python -m pipeline.review_due           # что пора пересмотреть
uv run python -m pipeline.fixtures             # пересобрать фикстуры и эталоны после правки данных
uv run pytest -q
```

## Что обновляется само

Раз в неделю `sync-data.yml` забирает снимки pal-norms и pal-directory и открывает PR. Если норма сменила статус и пакет не собирается, открывается issue с меткой `review:legal`. Раз в месяц `review_due` открывает issue о просроченных проверках, в том числе «Архивировать kit?» через 3 месяца демо без юриста.
